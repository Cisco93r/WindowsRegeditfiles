# WindowsRegeditfiles
⚙️ Windows Registry Power Pack ⚙️
A collection of registry tweaks to enhance performance, usability, and customization.
⚠️ Works on Windows 10 and 11. It's recommended to create a restore point before applying registry changes

📋 add copy & move.reg 📋
This registry tweak adds the "Copy to folder..." and "Move to folder..." options to the Windows right-click context menu, allowing you to quickly copy or move files and folders without opening multiple File Explorer windows.

🔍 Search Bing OUT.reg 🔍
This registry file disables Bing integration in the Windows Start Menu search, leaving only local file and app search active. After applying it:

Searches in the Start Menu will no longer show online results
Slightly improves Start Menu search performance
Local file and app search remains fully functional
